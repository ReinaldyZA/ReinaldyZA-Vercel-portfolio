LayanKita user manual: a 28-page guide for dashboard admins

A step-by-step guide for admins, health facility staff and developers who use the web dashboard, with a screenshot for every menu.

My role
System Analyst intern, author
Scope
Web dashboard, 4 staff roles
Context
Internship project. App, company, client, places and people are anonymized
Date
Internship Feb 2025 to Feb 2026. Rewritten for portfolio Nov 2026
Tools
Word
Deliverables
28-page user manual

The question

Can a new admin use the dashboard on day one without asking anyone?

Background

Admins and staff were trained before release. The manual is what they keep afterwards. The mobile app manual came from the developer team, so it is not shown here.

Method

  1. Listed the device requirements, such as a recent browser and a screen at least 1280 pixels wide.
  2. Wrote one chapter per menu, in the order an admin uses them.
  3. Added numbered steps and a screenshot for every task.
  4. Closed with a chapter on common problems and how to solve them.

What is inside

  • 11 chapters. From getting started and the overview to complaints, content, tickets, public information and regional data.
  • Numbered steps. Each task is a short list of clicks.
  • Screenshots. Every menu is shown as it appears on screen.
  • Troubleshooting. Common problems and what to do.
