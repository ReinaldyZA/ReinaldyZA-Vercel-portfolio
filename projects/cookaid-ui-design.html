Cookaid UI design: screens built from the user stories

High-fidelity Figma screens for Cookaid's onboarding, sign in and profile flows. Each screen answers a numbered user story in the PRD.

My role
UI designer (solo)
Scope
Onboarding, sign in, profile and settings
Program
MySkill Product & Project Management, and Figma for UI/UX
Date
October 2024
Tools
Figma
Deliverables
High-fidelity mobile screens

The question

What should each user story look like on a phone screen?

Background

The visual direction follows the brand idea "everyone can cook": a warm saffron yellow, friendly flat illustrations and large tap targets.

Method

  1. Started from the user journey in each PRD story.
  2. Designed the splash and onboarding to introduce the four core features.
  3. Designed sign in and sign up around the acceptance criteria, including Forgot Password.
  4. Designed the profile, saved recipes, settings and edit profile screens.

What is inside

  • Onboarding. Splash screen plus four screens: smart recipes, community, video tutorials and sharing.
  • Sign in and sign up. Email and password, plus Google and Apple sign up.
  • Profile. Posts, saved recipes, settings and edit profile.
